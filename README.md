### 1. Palindrome Number

**Purpose:** Check whether a number reads the same forward and backward.

**Logic:**

1. Accept a number from the user.
2. Reverse the digits using a loop.
3. Compare the reversed number with the original number.
4. If both are equal, it is a palindrome.

---

### 2. Palindrome String

**Purpose:** Check whether a string is a palindrome.

**Logic:**

1. Take a string input.
2. Reverse the string using slicing.
3. Compare the original and reversed strings.
4. If both are equal, the string is a palindrome.

---

### 3. Positive or Negative Number

**Purpose:** Identify the nature of a number.

**Logic:**

1. Accept a number from the user.
2. If the number is 0, display "Zero".
3. If greater than 0, display "Positive".
4. Otherwise, display "Negative".

---

### 4. Factorial of a Number

**Purpose:** Calculate the factorial of a positive integer.

**Logic:**

1. Accept a positive integer.
2. Initialize factorial value as 1.
3. Multiply factorial by every number from 1 to n.
4. Display the final factorial value.

---

### 5. Swap Two Numbers

**Purpose:** Exchange the values of two variables.

**Logic:**

1. Take two numbers as input.
2. Store the first number in a temporary variable.
3. Assign the second number to the first variable.
4. Assign the temporary value to the second variable.
5. Display the swapped values.

---

### 6. Simple Interest

**Purpose:** Calculate simple interest.

**Logic:**

1. Accept principal amount, rate of interest, and time.

2. Apply the formula:

   Simple Interest = (Principal × Rate × Time) / 100

3. Display the calculated interest.

**Logic:**

4. Otherwise, it is not divisible by both.

### 6. Student Percentage Calculator

**Purpose:** Calculate percentage based on subject marks.

**Logic:**

1. Accept the number of subjects.

2. Take marks for each subject.

### 7. Scholarship Eligibility

**Purpose:** Determine scholarship eligibility.

**Logic:**

1. Accept percentage and age.
2. Check if percentage is at least 85%.

5. Otherwise, the student is not eligible.

### 9. House Rent Calculator

**Purpose:** Calculate total housing cost and cost per person.

**Logic:**

3. Divide the total expense by the number of residents.

### 10. ATM Withdrawal Check

**Purpose:** Verify whether withdrawal is possible.

**Logic:**

2. Compare withdrawal amount with available balance.
